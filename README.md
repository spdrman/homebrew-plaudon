# Plaudon tap

A Homebrew tap carrying one cask, `plaudon`.

```sh
brew tap spdrman/plaudon
brew install --cask plaudon
plaudon-setup-plaud
```

Plaudon is a local-first desktop application for importing, transcribing and
reviewing your own recordings. The source, the issue tracker and the releases
live in [spdrman/plaudon](https://github.com/spdrman/plaudon); this repository
holds nothing but the cask.

## What you are installing

* **Apple Silicon only.** The cask declares `depends_on arch: :arm64`; there is
  no Intel build.
* **Unsigned and not notarized.** The bundle is built without a Developer ID
  certificate and is not sent to Apple for notarization. Gatekeeper will refuse
  to open it until you clear the quarantine attribute yourself, and the cask's
  own caveats print the exact command. Treat it as what it is: software you
  chose to run without Apple having vouched for it.
* **Node.js.** The cask depends on the `node` formula and installs the one
  version of the official PLAUD Cloud CLI (`@plaud-ai/cli`) that Plaudon is
  verified against. `plaudon-setup-plaud` runs the guided sign-in.

## How the cask gets here

`Casks/plaudon.rb` is generated by the release workflow in the application
repository from the artifact it just built — the URL and the SHA-256 are read
off that file, never typed — and pushed here. It is not edited by hand.
